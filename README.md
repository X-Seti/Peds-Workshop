# Ped Workshop

GTA ped editor and animator for GTA III, Vice City, San Andreas (and GTA IV ped data).

Companion tool to [IMG Factory 1.6](https://github.com/X-Seti/Img-Factory-1.6), built on
[Model Workshop](https://github.com/X-Seti/Model-Workshop).

## Features
- Peds list from peds.ide / default.ide - edit and save (changed rows only, backup first)
- Ped data files: ped.dat, pedgrp.dat, pedstats.dat, animgrp.dat, clothes.dat,
  shopping.dat, popcycle.dat, Decision files, GTA IV ped data
- Ped preview: DFF + TXD straight from models/gta3.img
- IFP animations (ANPK III/VC, ANP3 SA, SA anim.img): play, loop, speed, in place
- Stick-man bones: click a joint to select, drag to rotate
- Stop-motion keyframes: pose a bone, Set key, step frames, save IFP

## Run
    ./launch_ped_workshop.py [game folder]
